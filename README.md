# A Little Note for You

A static, responsive HTML/CSS/JavaScript surprise page published at [https://jusrandtzn.github.io/a-little-note-for-you/](https://jusrandtzn.github.io/a-little-note-for-you/).

The site and QR page are served from the root of the public `jusrandtzn/a-little-note-for-you` repository through GitHub Pages. The included `qr-code.png` and `qr-code.svg` point to the public site URL above.

The gate is only a playful front-end interaction. Credentials are in `script.js`, so anyone can inspect them or bypass the gate. Do not use it to protect confidential material. The page also contains a personal photo and story; publishing makes those available to anyone with the URL (and potentially search engines).

## Files

- `index.html`, `style.css`, `script.js` — site
- `couple.jpg` — attached photo used in the sliding puzzle
- `qr.html`, `qr-code.png`, `qr-code.svg` — themed QR display and print-ready vector/raster codes for the public GitHub Pages URL
